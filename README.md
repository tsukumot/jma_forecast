# JMA Forecast

気象庁の「府県天気予報（Ｒ１）電文」を使い、天気・気温・風の予報をHome Assistantに表示するカスタム統合です。

- 3時間ごとの予報（天気・気温・風向・風速）を取得します。
- センサー2つ（気温予報・天気予報）と、天気エンティティ（`weather`）を作成します。
- 3つのエンティティは1つのデバイス「JMA 予報」にまとまります。
- 複数地点の予報を取得することが可能です。
- YAMLの編集は不要です。
- 電文更新時に内容が変わらないときは再解析せず、キャッシュを使います。

> データの出典：気象庁

## インストール

### HACS（カスタムリポジトリ）

1. HACS → 右上のメニュー → **カスタムリポジトリ**
2. リポジトリに `https://github.com/tsukumot/jma_forecast`、種類に **Integration** を指定して追加
3. 「JMA Forecast」をダウンロードし、Home Assistant を再起動

### 手動

1. このリポジトリの内容を `config/custom_components/jma_forecast/` にコピー
2. Home Assistantを再起動

## 設定

1. **設定 → デバイスとサービス → 統合を追加** で「JMA Forecast」を選択
2. **地方** を選ぶ（例：北陸地方）
3. **府県予報区** を選ぶ（例：新潟県）
4. **一次細分区域（天気）** と **地点（気温）** を選ぶ（例：中越／観測地点）

複数の地点を登録することもできます。
同じ府県予報区を2つ以上登録した場合、2つ目以降は地点名がタイトルに付きます。

> `configuration.yaml` への `platform: jma_forecast` の記述は不要です。

### 「この府県予報区の予報電文がまだ配信されていません」と出たら

Ｒ１電文は、気象庁が発表した時点でフィードに載ります。
選んだ府県予報区の電文がフィードにまだ無いと、選択肢を作れず設定が中断されます。
しばらくしてからもう一度お試しください。

## 作成されるエンティティ

| エンティティ | 種類 | 内容 | 更新間隔 |
| --- | --- | --- | --- |
| 気温予報 | `sensor`（温度） | 現在時刻に該当する枠の気温（℃） | 10分 |
| 天気予報 | `sensor` | 現在時刻に該当する枠の天気（例：晴れ、くもり） | 10分 |
| 天気 | `weather` | 天気・気温・風向・風速、および1時間単位の予報（`forecast_hourly`） | 30分 |

天気エンティティの天気は、気象庁の文言から Home Assistant の `condition` に次のように変換されます。

| 文言に含まれる語 | condition |
| --- | --- |
| 雪 と 雨 | `snowy-rainy` |
| 雷 | `lightning` |
| 雪 | `snowy` |
| 雨 | `rainy` |
| 霧 | `fog` |
| くもり／曇 | `cloudy` |
| 晴（日没後） | `clear-night` |
| 晴（日中） | `sunny` |

上から順に判定するため、「雨で雷を伴う」のような文言は `lightning` になります。

## 制限・注意

- 予報は3時間ごとです。`forecast_hourly` には、現在の3時間前以降の枠がそのまま入ります（1時間ごとに補間はしません）。
- 風速は、電文の風速レベルの範囲（下限・上限）の平均値を m/s として扱います。
- 日没後かどうかの判定は、天気エンティティの現在値では `sun.sun`、`forecast_hourly` では 18時〜6時 の簡易判定です。
- 地方・府県予報区の一覧は同梱の `area.json` から読み込みます。気象庁側の区域改定があった場合、このファイルの差し替えが必要です。[元データ](https://www.jma.go.jp/bosai/common/const/area.json)は気象庁のものです。
- 電文の発表間隔や内容は気象庁の運用に依存します。
